# Retail Sales Performance Analysis using Excel, SQL & Power BI

## Project Overview
This project is an end-to-end Retail Sales Analytics project built using Excel, SQL, and Power BI. The main objective of this project is to clean raw retail sales data, perform exploratory data analysis (EDA), and create an interactive dashboard to generate meaningful business insights.

The dashboard helps analyze:
- Sales performance
- Profitability
- Customer behavior
- Product performance
- Regional and market trends

---

## Tools & Technologies Used
- Excel → Data Cleaning
- MySQL → SQL Analysis
- Power BI → Dashboard & Visualization

---

## Dataset
The dataset contains retail sales information including:
- Orders
- Customers
- Products
- Categories
- Regions
- Markets
- Sales
- Profit
- Quantity

---

## Data Cleaning Performed
Data cleaning was performed using Excel:
- Removed duplicate records
- Handled missing values
- Standardized date formats
- Fixed inconsistent text values
- Corrected data types
- Removed extra spaces
- Prepared clean dataset for analysis

---

## SQL Analysis
Performed exploratory data analysis using SQL queries:
- Total Sales & Profit Analysis
- Region-wise Sales Analysis
- Category-wise Performance
- Top Customers Analysis
- Top Selling Products
- Monthly Sales Trends
- Profitability Analysis
- Market-wise Revenue Analysis

## Business Insights
- Technology category generated the highest sales.
- Consumer segment contributed the highest revenue.
- Some sub-categories generated negative profit.
- Sales performance varied across different regions and markets.
- Top customers contributed significantly to overall revenue.
